A versatile, cross-platform programming language inspired by the Maned Wolf (Chrysocyon brachyurus).

About Rudy

Rudy is a multipurpose programming language designed to unite panoramic readability, cross-platform portability (PC and Termux/Android), and complete flexibility. Inspired by the Maned Wolf, Rudy empowers developers to build anything: from text-based games and ASCII animations to utilities, calculators, and system scripts.

  • Bilingual Syntax Support: Write natively using either English keywords (action, write, while, if, else, ask) or Portuguese keywords (acao, escrever, enquanto, se, senao, ler).
  • Multipurpose Engine: Capable of handling logic, math, random generation, file persistence, and terminal timing.
  • Lightweight & Portable: Built with a clean Python interpreter core, running smoothly across desktop environments and mobile terminals.

Interactive Code Example (.rudy)

// Interactive adventure example in Rudy
action main() {
    write("=== WELCOME TO RUDY ===")
    name = ask("What is your character name? ")
    hp = 50
    write("Hello, " + name + "! Your initial HP is " + hp)
    
    damage = random(10, 25)
    hp = hp - damage
    write("A wild obstacle appeared and caused " + damage + " damage!")
    
    if (hp > 25) then {
        write("Status: You are still strong!")
    } else {
        write("Status: Warning! HP is low!")
    }
}

Core Features

⚡ Input & Output: write(…) / escrever(…) and ask(…) / ler(…)

🔄 Control Flow: if (…) then { … } else { … } and while (…) { … }

🎲 Randomization & Math: random(min, max) / aleatorio(min, max) and arithmetic

⏱️ Time & Animation: sleep(seconds) and clear() for ASCII frame rendering

💾 File Persistence: save(path, content) and load(path)
