🐺 Rudy Programming Language

A lightweight, bilingual (PT/EN) AST-based programming language designed for portability, retro ASCII games, and automation.

Sobre / About

PT: Rudy é uma linguagem de programação leve e bilíngue focada em portabilidade, motores AST limpos, jogos retro em ASCII e automação eficiente.

EN: Rudy is a lightweight, bilingual programming language focused on portability, clean AST engines, retro ASCII games, and efficient automation.

Exemplo de Código / Code Example

// Exemplo em Rudy / Rudy Example
imprimir("Olá, Mundo do Rudy! 🐺");
saudacao("Luis Felipe");

Recursos / Features

⚡ Interpretador AST robusto em Python

🌐 Suporte Bilíngue nativo (Português / English)

📦 Empacotamento Standalone com PyInstaller

📝 Extensão dedicada para VS Code
