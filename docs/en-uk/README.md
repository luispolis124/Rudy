## Quick Overview

Rudy runs on a robust Abstract Syntax Tree (AST) engine built in Python, featuring standalone compilation capabilities (`--build`) via PyInstaller and a built-in package manager (`rudy install`) for standard library modules.

For examples of complete scripts and retro ASCII games, check out the [`examples/`](../examples/) directory in the root of the repository!
