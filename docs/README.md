# Rudy Documentation 🐺

Welcome to the official documentation hub for **Rudy**, a lightweight, bilingual (PT/EN) programming language designed for portability, retro game development, and automation across PCs and mobile environments (like Termux).

---

## Available Guides

* **[Functions Reference (`FUNCTIONS.md`)](./FUNCTIONS.md)**: Comprehensive guide to native I/O commands, file management, system utilities, math functions, and bilingual control flow.
* **[Error Reference (`ERRORS.md`)](./ERRORS.md)**: Troubleshooting guide detailing lexical exceptions, parser syntax errors, and runtime warnings.

---

## Quick Overview

Rudy runs on a robust Abstract Syntax Tree (AST) engine built in Python, featuring standalone compilation capabilities (`--build`) via PyInstaller. 

For examples of complete scripts and retro ASCII games, check out the [`examples/`](../examples/) directory in the root of the repository!
