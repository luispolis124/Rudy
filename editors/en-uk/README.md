# English (United Kingdom) Editor Support

Rudy editor integrations support both `.rudy` syntax and the English and Portuguese keyword sets.

## VS Code

Install the extension from `editors/en-uk/vscode/`, then open a `.rudy` file.

## Neovim

Copy or link `editors/en-uk/neovim/` using the setup from [the Neovim guide](./neovim/README.md).
