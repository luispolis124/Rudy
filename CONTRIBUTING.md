# Contributing to Rudy

First off, thank you for taking the time to contribute! **Rudy** is an open-source, multipurpose programming language inspired by the Maned Wolf, crafted in Brazil 🇧🇷 for the global community. 

To make your contribution process as smooth as possible, please follow these guidelines.

---

## Code of Conduct

By participating in this project, you agree to maintain a welcoming, respectful, and collaborative environment for everyone.

---

## How Can I Contribute?

### 1. Reporting Bugs & Issues
If you encounter a bug in the interpreter, lexer, parser, or runtime:
* Check existing **Issues** to see if the bug has already been reported.
* If not, open a new Issue with a clear title and description.
* Include steps to reproduce the bug and attach any relevant `.rudy` code snippets.

### 2. Suggesting Enhancements
Have an idea for a new bilingual keyword, runtime function, or compiler feature?
* Open an Issue detailing your feature proposal.
* Explain why this feature would be useful for the community (e.g., game development, ASCII animation, utilities).

### 3. Pull Requests (PRs)
1. **Fork** the repository and create your branch from `main`:
   ```bash
   git checkout -b feature/sua-nova-feature

 * Make your changes in the codebase (src/rudy.py, examples/, etc.).
 * Test your changes locally to ensure everything runs smoothly:
   python src/rudy.py examples/seu_teste.rudy

 * Commit your changes with a clear and descriptive commit message:
   git commit -m "feat: adiciona suporte a nova funcionalidade X"

 * Push to your fork and submit a Pull Request to the main repository.
Project Structure Reference
 * assets/ — Logos, icons, and official brand images.
 * src/ — Core source code of the language (rudy.py containing Lexer, Parser, Runtime, and Compiler).
 * examples/ — Sample .rudy programs, games, and scripts.
 * README.md — Main documentation.
Thank you for helping build and grow Rudy! 🐺🇧🇷
