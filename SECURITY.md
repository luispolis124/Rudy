# Security Policy

## Supported Versions

We are committed to ensuring the security of the **Rudy** programming language. As an active open-source project in development, security updates are provided for the latest stable release.

| Version | Supported          |
| ------- | ------------------ |
| v1.x    | :white_check_mark: |
| < v1.0  | :x:                |

---

## Reporting a Vulnerability

If you discover a security vulnerability within the Rudy interpreter, compiler, or standard environment, we appreciate your help in disclosing it responsibly. 

* **Please do NOT open public GitHub issues** for security-related matters.
* Instead, please report vulnerabilities directly via email to the core maintainer:
  * **Email:** `luisfelipovi@gmail.com`

### What to include in the report:
* A description of the vulnerability and potential impact.
* Steps or a minimal `.rudy` script to reproduce the issue.
* Any relevant environment details (OS, Python version, Termux setup, etc.).

We will review your report promptly, work on a fix, and coordinate the disclosure timeline with you. Thank you for helping keep Rudy secure!
